# Fundamentos de Java — if-else e while

Coleção de programas básicos em Java, desenvolvidos como exercício de lógica de programação,
utilizando exclusivamente estruturas condicionais (`if-else`) e de repetição (`while`).

## Programas

- **CalculadoraSimples** — soma, subtração, multiplicação e divisão de dois números
- **CalculoIMC** — cálculo e classificação do Índice de Massa Corporal
- **CalculoINSS** — contribuição previdenciária pela tabela progressiva
- **CalculoImpostoRenda** — cálculo do IRRF descontado na fonte
- **NumerosParesImpares** — números pares e ímpares em um intervalo
- **FatorialNumero** — cálculo de fatorial
- **Tabuada** — tabuada de 1 a 10 de um número
