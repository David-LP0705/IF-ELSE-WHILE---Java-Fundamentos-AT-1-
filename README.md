# ☕ Fundamentos de Java — Estruturas de Controle

Repositório dedicado a exercícios práticos de lógica de programação utilizando **Java**, focando no domínio de estruturas condicionais (`if-else`) e de repetição (`while`).

---

## 📂 Programas Desenvolvidos

O projeto conta com uma coleção de algoritmos focados em resolver problemas comuns de lógica e matemática:

* **CalculadoraSimples** — Realiza operações básicas (soma, subtração, multiplicação e divisão) entre dois números.
* **CalculoIMC** — Realiza o cálculo e a classificação do Índice de Massa Corporal.
* **CalculoINSS** — Calcula a contribuição previdenciária com base na tabela progressiva.
* **CalculoImpostoRenda** — Calcula o Imposto de Renda Retido na Fonte (IRRF).
* **NumerosParesImpares** — Identifica e separa números pares e ímpares em um determinado intervalo.
* **FatorialNumero** — Efetua o cálculo de fatorial de um número informado.
* **Tabuada** — Gera a tabuada de multiplicação de 1 a 10 de um número.

---

## 🛠️ Tecnologias e Ferramentas

* **Java (JDK):** Linguagem de programação orientada a objetos utilizada para implementar a lógica.
* **IDE (VS Code / IntelliJ / Eclipse):** Ambiente de desenvolvimento para escrita e execução dos códigos.
